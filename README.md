## 🏗️ Workflow: How it Works
This repository is powered by an automated "Second Brain" pipeline:

1.  **Capture:** I write and refine technical notes in my private Obsidian vault (`second-brain`).
2.  **Flag:** When a note is ready for public sharing, I add `publish: true` to its YAML frontmatter.
3.  **Sync:** Running the custom `publish_notes.py` script automatically:
    - Identifies all flagged notes.
    - Resolves and copies required assets (images/diagrams).
    - Commits and pushes changes to this repository.
4.  **Deploy:** A GitHub Action triggers on every push, building the site with **Quartz** and deploying it to GitHub Pages.
